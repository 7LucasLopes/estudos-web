# Estudos Web

Repositório dedicado aos meus estudos e práticas durante a formação Full Stack da Rocketseat.

Aqui registro exercícios, desafios e projetos desenvolvidos ao longo do aprendizado, utilizando tecnologias e conceitos de desenvolvimento web.

## Tecnologias e conceitos

- HTML5
- CSS3
- JavaScript
- Manipulação do DOM
- CSS Flexbox e Grid
- Git e GitHub

## Projetos e práticas

### Quicklist
Aplicação de lista de compras desenvolvida para praticar manipulação do DOM com JavaScript.

Principais funcionalidades:
- Adicionar itens;
- Marcar itens como concluídos;
- Remover itens da lista;
- Exibir mensagens de confirmação.

### Outros exercícios

O repositório também contém exercícios e projetos menores voltados à prática de estruturação de páginas, estilização, construção de layouts e lógica com JavaScript.

## Objetivo

Documentar minha evolução durante a formação Full Stack, consolidando os fundamentos do desenvolvimento web por meio da prática.
