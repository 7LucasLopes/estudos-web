# Estudos Web

Repositório dedicado aos meus estudos e práticas durante a formação Full Stack da Rocketseat.

Aqui reúno exercícios, desafios e projetos desenvolvidos ao longo da minha jornada de aprendizado em desenvolvimento web. O objetivo é registrar minha evolução, aplicar os conhecimentos adquiridos e desenvolver minha capacidade de resolver problemas.

## Tecnologias e conceitos estudados

- **HTML5:** estruturação de páginas web.
- **CSS3:** estilização, responsividade e construção de layouts.
- **JavaScript:** lógica de programação, manipulação do DOM e interatividade.
- **Git e GitHub:** versionamento e organização de projetos.

## Projetos e práticas

Neste repositório estão reunidos projetos e exercícios com diferentes níveis de complexidade e abordagens de desenvolvimento.

| Projeto | Descrição |
|---|---|
| **Projeto Receita** | Prática de desenvolvimento web realizada de forma independente. |
| **Local Turístico** | Exercício de construção de uma página web, aplicando HTML e CSS. |
| **Quicklist** | Aplicação de lista de compras com funcionalidades de adição, conclusão e remoção de itens. |
| **Sorteador de Números** | Exercício prático para trabalhar conceitos de programação e JavaScript. |
| **Zingen** | Projeto desenvolvido durante a formação, com orientação do professor. |

Alguns projetos foram desenvolvidos com orientação, enquanto outros foram tentativas de aplicação independente dos conhecimentos adquiridos. Também utilizei ferramentas de inteligência artificial como apoio em algumas etapas do desenvolvimento.

## Objetivo

Consolidar os fundamentos do desenvolvimento web, ampliar meus conhecimentos em JavaScript e ganhar autonomia na construção de aplicações.

Este repositório representa parte da minha trajetória de aprendizado em desenvolvimento de software.
